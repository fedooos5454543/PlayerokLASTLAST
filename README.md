# Playerok → Telegram бот

Уведомления о продажах, пересылка сообщений от покупателей и авто-перевыставление проданных товаров.
Весь код — в одном файле `main.py`, чтобы было проще разобраться.

⚠️ **Важно понимать перед использованием.** Playerok не даёт продавцам официального публичного API.
Бот использует неофициальную библиотеку [`PlayerokAPI`](https://github.com/alleexxeeyy/PlayerokAPI),
которая работает от имени вашего аккаунта через куки авторизованной сессии (по сути — как автоматизированный
браузер без браузера). Из этого следует:

- Куки периодически "протухают" (особенно `__ddg5_`, cookie антибот-защиты) — их надо будет обновлять из браузера.
- Такая автоматизация формально не входит в предусмотренные площадкой способы взаимодействия — есть шанс,
  что при подозрительной активности сработает защита или аккаунт привлечёт внимание модерации. Рекомендую
  сначала протестировать на некритичном аккаунте / небольшом обороте.
- Библиотека сторонняя (не от Playerok и не от Anthropic) — обновления Playerok могут её сломать.

## Что умеет бот

1. **Уведомление о продаже** — как только покупатель оплачивает товар, в Telegram прилетает сообщение
   с названием товара, ценой и ником покупателя.
2. **Пересылка сообщений** — все входящие сообщения от собеседников в чатах Playerok дублируются в Telegram.
3. **Авто-перевыставление** (опционально, `AUTO_RELIST=true`) — после продажи бот создаёт копию товара
   (та же категория, способ получения, цена, описание, фото, поля) и сразу публикует её.
   ⚠️ Для некоторых категорий (с нестандартными опциями) копия может потребовать ручной проверки —
   бот присылает отдельное предупреждение после каждого релиста.

## Файлы проекта

- `main.py` — весь код бота (настройки, Telegram, авто-релист, главный цикл).
- `requirements.txt` — список зависимостей.
- `.env.example` — шаблон файла с настройками (токены, куки).

## Установка

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

## Настройка `.env`

### 1. Telegram-бот
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → следуйте инструкциям → получите `TG_BOT_TOKEN`.
2. Узнайте свой `chat_id`: напишите что-нибудь боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш ID.
   Впишите его в `TG_CHAT_ID`.

### 2. Куки Playerok
1. Откройте [playerok.com](https://playerok.com) в браузере и залогиньтесь в свой аккаунт-продавец.
2. Откройте DevTools (F12) → вкладка **Network** → обновите страницу → кликните на любой запрос к `playerok.com`.
3. В заголовках запроса найдите `Cookie:` и скопируйте **всю строку целиком** — это значение для `PLAYEROK_COOKIES`.
4. Там же скопируйте `User-Agent` из заголовков — впишите в `PLAYEROK_USER_AGENT` (важно: запросы бота должны
   идти "под тем же браузером", иначе антибот-защита может сработать).

### 3. Авто-релист
Оставьте `AUTO_RELIST=true`, если хотите, чтобы товар автоматически перевыставлялся после продажи.
`RELIST_PRIORITY_STATUS_ID` можно не трогать — бот сам выберет бесплатный статус публикации.

## Запуск

```bash
python main.py
```

Бот пришлёт в Telegram сообщение "Бот запущен" и дальше будет работать в фоне, пока не остановите его
(Ctrl+C) или не выключите машину. Для постоянной работы разверните его на сервере/VPS, например через
`systemd`, `pm2`, `screen`/`tmux` или Docker.

## Частые проблемы

- **`BotCheckDetectedException` / бот пишет про "потерял доступ"** — куки протухли (обычно `__ddg5_`).
  Заново зайдите на playerok.com в том же браузере, скопируйте свежие куки и обновите `.env`.
- **Бот не видит новые сообщения/сделки сразу** — `EventListener` работает поллингом (периодическим опросом),
  а не вебхуками (площадка их не предоставляет), поэтому задержка в несколько секунд — это нормально.
- **Авто-релист скопировал товар "не так"** — для сложных категорий (с обязательными опциями/доп. полями)
  всегда проверяйте карточку вручную после релиста; бот присылает напоминание об этом каждый раз.
